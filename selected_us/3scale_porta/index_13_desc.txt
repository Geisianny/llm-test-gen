The Red Hat 3scale API Management system (Porta), responsible for providing an administration portal for API providers, must offer providers a list of their customers' service subscriptions, allowing them to view, search, filter, and sort these subscriptions. The page should display the status, plan, billing type, value, service, and other relevant information for each subscription, and must support filters by account, service, plan, status, and payment type. When there are no results, the system must display appropriate empty states.
