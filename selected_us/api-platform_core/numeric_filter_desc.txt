The API Platform Core is the resource publishing component that allows exposing and managing REST and GraphQL APIs using hypermedia formats. The system must allow the filtering of collections by numerical values, supporting the use of single parameters, multiple parameters (arrays), and property converters in the query string. The system must provide valid responses in the JSON-LD format (`application/ld+json`), structured according to the Hydra vocabulary (including `hydra:view` and search templates), and must handle non-numerical inputs resiliently, maintaining a 200 status return and the collection structure. This ensures interoperability and the correct validation of pagination metadata.
