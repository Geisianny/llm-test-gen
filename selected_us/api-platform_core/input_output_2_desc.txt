The API Platform Core is the resource publishing component that allows exposing and managing REST and GraphQL APIs using hypermedia formats. The system must support input and output DTOs in the application/json format, allowing for simplified structures outside the strict JSON:API standard. It must validate content headers and process specific workflows, such as password reset, ensuring it returns a 201 status with the dispatch timestamp for success, or a 404 status in the problem+json format for non-existent users. This guarantees exact compliance with the defined interface contracts.
