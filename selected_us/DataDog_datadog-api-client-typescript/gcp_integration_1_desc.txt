Datadog is an observability and security platform for cloud applications, integrating and automating infrastructure monitoring, application performance monitoring, log management, and user experience monitoring. The system must allow the configuration of the Datadog-GCP integration via API, focusing on the management of STS (Security Token Service) service accounts, enabling the creation, listing, updating, and deletion of these accounts, while configuring attributes such as filters and security options (CSPM, Security Command Center).
