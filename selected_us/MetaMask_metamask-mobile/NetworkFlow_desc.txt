MetaMask Mobile Performance is a performance testing module for the iOS version of the mobile wallet that provides access to sites using the Ethereum blockchain. The system must allow users to add and manage custom blockchain networks through two distinct methods: a list of pre-configured popular networks (such as Palm and Optimism) and a complete manual setup (with fields for name, RPC URL, Chain ID, and symbol). This includes secure approval processes and the ability to remove added networks, ensuring flexibility and total control over the wallet's connections.
