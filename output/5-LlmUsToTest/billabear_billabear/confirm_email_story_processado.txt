Scenario: Confirm account with valid verification code
  Given there is a user who has registered with a valid email "user@example.com"
  And the system has sent a verification code to "user@example.com"
  When the user enters the correct verification code
  Then the system confirms the user's account
  And the user's account status is updated to confirmed

Scenario: Attempt to confirm account with invalid verification code
  Given there is a user who has registered with a valid email "user@example.com"
  And the system has sent a verification code to "user@example.com"
  When the user enters an incorrect verification code
  Then the system does not confirm the user's account
  And the user's account status remains unconfirmed

Scenario: Confirm account with expired verification code
  Given there is a user who has registered with a valid email "user@example.com"
  And the system has sent a verification code to "user@example.com" that has expired
  When the user enters the expired verification code
  Then the system does not confirm the user's account
  And the user's account status remains unconfirmed
  And the system displays a message indicating that the verification code has expired

Scenario: Request new verification code
  Given there is a user who has registered with a valid email "user@example.com"
  And the system has sent a verification code to "user@example.com"
  When the user requests a new verification code
  Then the system sends a new verification code to "user@example.com"
  And the previous verification code is invalidated

Scenario: Confirm account with already confirmed user
  Given there is a user who has registered with a valid email "user@example.com"
  And the user's account is already confirmed
  When the user enters a verification code
  Then the system displays a message indicating that the account is already confirmed
  And the user's account status remains confirmed
