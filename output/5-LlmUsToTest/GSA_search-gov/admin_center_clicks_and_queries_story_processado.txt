Scenario: View top clicked URLs
  Given there are search queries and corresponding clicked URLs in the system
  When the site administrator views the top clicked URLs report
  Then the system displays a list of top clicked URLs
  And the list includes the number of clicks for each URL

Scenario: Analyze queries that led to a clicked URL
  Given there is a clicked URL with associated search queries in the system
  When the site administrator selects a clicked URL to analyze
  Then the system displays the search queries that led to the clicked URL
  And the list includes the frequency of each query

Scenario: View clicked URLs from a specific query
  Given there is a search query with associated clicked URLs in the system
  When the site administrator selects a search query to analyze
  Then the system displays the clicked URLs that resulted from the query
  And the list includes the number of clicks for each URL

Scenario: Generate monthly report of query and click correlation
  Given there are search queries and corresponding clicked URLs in the system for the current month
  When the site administrator requests a monthly report
  Then the system generates a report showing the correlation between search queries and clicked URLs
  And the report includes the top clicked URLs and their corresponding queries

Scenario: No data available for query and click correlation
  Given there are no search queries or clicked URLs in the system
  When the site administrator views the top clicked URLs report
  Then the system displays a message indicating that there is no data available
  And provides guidance on how to start collecting data
