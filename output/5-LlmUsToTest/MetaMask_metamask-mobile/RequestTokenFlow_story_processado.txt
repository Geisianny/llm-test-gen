Scenario: Request native token successfully
  Given the user has a configured network with native token "ETH"
  When the user requests the native token "ETH"
  Then the system generates a payment link for "ETH"
  And displays a QR code for "ETH"

Scenario: Request ERC-20 token successfully
  Given the user has a configured network with ERC-20 token "Link"
  When the user requests the ERC-20 token "Link"
  Then the system generates a payment link for "Link"
  And displays a QR code for "Link"

Scenario: Request token with unconfigured network
  Given the user does not have a configured network with native token "BNB"
  When the user requests the native token "BNB"
  Then the system displays a message indicating that the network is not configured
  And does not generate a payment link or QR code

Scenario: Request invalid token
  Given the user has a configured network
  When the user requests an invalid token "InvalidToken"
  Then the system displays a message indicating that the token is invalid
  And does not generate a payment link or QR code

Scenario: Share payment link and QR code
  Given the user has generated a payment link and QR code for "ETH"
  When the user shares the payment link and QR code
  Then the system allows the recipient to access the payment link
  And the recipient can send "ETH" to the user's wallet
