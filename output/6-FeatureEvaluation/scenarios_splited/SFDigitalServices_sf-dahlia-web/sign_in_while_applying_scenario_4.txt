Scenario: Reconcile conflicting data during sign-in
  Given there is a user with an existing account with different date of birth than the anonymous application
  And the user is filling out an application anonymously for a senior-specific listing
  When the user chooses to sign in with their account
  And enters valid email and password
  Then the system prompts the user to reconcile the conflicting date of birth
  And provides options to use the account data or continue with the anonymous data
