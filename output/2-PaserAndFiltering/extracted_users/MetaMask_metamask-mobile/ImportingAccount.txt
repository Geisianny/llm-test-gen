Feature: Import Account
Tags: ['@androidApp', '@regression', '@accounts']

Scenario 1: Import Wallet
  Given  the app displayed the splash animation
  And  I have imported my wallet
  And  I tap No Thanks on the Enable security check screen
  And  I tap No thanks on the onboarding welcome tutorial

Scenario Outline 2: Import an account using an invalid private key - Example 1
  Given  I am on the wallet view
  When  I tap on the Identicon
  Then  the account list should be visible
  When  I tap import account
  Then  I am taken to the Import Account screen
  When  I type 23423411x into the private key input field
  And  I tap on the private key import button
  Then  I should see an error We couldn't import that private key.
  And  I close the import account screen
  When  I tap on the Identicon
  Then  the account list should not be visible

  Examples:
    | PRIVATEKEY | warning |
    | 23423411x | We couldn't import that private key. |

Scenario Outline 3: Import an account using a valid private key - Example 1
  Given  I am on the wallet view
  When  I tap on the Identicon
  Then  the account list should be visible
  When  I tap import account
  Then  I am taken to the Import Account screen
  When  I type cbfd798afcfd1fd8ecc48cbecb6dc7e876543395640b758a90e11d986e758ad1 into the private key input field
  And  I tap on the private key import button
  Then  The account is imported
  And  I am on the wallet view

  Examples:
    | PRIVATEKEY |
    | cbfd798afcfd1fd8ecc48cbecb6dc7e876543395640b758a90e11d986e758ad1 |
