Feature: Webhooks Integration
Description: Configure your Datadog-Webhooks integration directly through the Datadog
  API. See the [Webhooks integration

  information.
Tags: ['@endpoint(webhooks-integration)', '@endpoint(webhooks-integration-v1)']

Background: 
  Given  a valid "apiKeyAuth" key in the system
  And  a valid "appKeyAuth" key in the system
  And  an instance of "WebhooksIntegration" API

Scenario 1: Create a custom variable returns "Bad Request" response
  Tags: ['@generated', '@skip', '@team:Datadog/collaboration-integrations']
  Given  new "CreateWebhooksIntegrationCustomVariable" request
  And  body with value {"is_secret": true, "name": "CUSTOM_VARIABLE_NAME", "value": "CUSTOM_VARIABLE_VALUE"}
  When  the request is sent
  Then  the response status is 400 Bad Request

  Tags: ['@skip-terraform-config', '@team:Datadog/collaboration-integrations']
