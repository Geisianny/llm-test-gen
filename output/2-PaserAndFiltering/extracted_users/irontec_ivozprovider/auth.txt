Feature: Authorization checking
Description: In order to use the API
  As a client software developer
  I need to be authorized to access a given resource.

Scenario 1: An anonymous user cannot retrieve a secured resource
  Tags: ['@createSchema']
  When  I add "Accept" header equal to "application/ld+json"
  And  I send a "GET" request to "companies"
  Then  the response status code should be 401

Scenario 2: An authenticated user can retrieve a secured resource
  When  I add Brand Authorization header
  And  I add "Accept" header equal to "application/ld+json"
  And  I send a "GET" request to "companies"
  Then  the response status code should be 200
  And  the response should be in JSON

Scenario 3: A higher order admin can exchange token
  When  I exchange Brand Authorization header
  And  I add "Accept" header equal to "application/ld+json"
  And  I send a "GET" request to "companies"
  Then  the response status code should be 200
  And  the response should be in JSON

Scenario 4: A higher order admin cannot exchange token
  Given  I exchange restrictedPlatformAdministrator platform token for restrictedBrandAdmin brand token
  And  I add "Accept" header equal to "application/ld+json"
  And  I send a "GET" request to "companies"
  Then  the response status code should be 401
  And  the response should be in JSON

Scenario 5: A higher order admin can exchange internal token
  When  I exchange internal Brand Authorization header
  And  I add "Accept" header equal to "application/ld+json"
  And  I send a "GET" request to "companies"
  Then  the response status code should be 200
  And  the response should be in JSON

Scenario 6: An authenticated brand user retrieve a secured resource
  Given  I add Brand Authorization header
  And  I add "Accept" header equal to "application/json"
  And  I send a "GET" request to "/services/unassigned"
  Then  the response status code should be 200
  And  the response should be in JSON

Scenario 7: Unauthenticated brand users cannot retrieve a secured resource
  And  I add "Accept" header equal to "application/json"
  And  I send a "GET" request to "/services/unassigned"
  Then  the response status code should be 401
