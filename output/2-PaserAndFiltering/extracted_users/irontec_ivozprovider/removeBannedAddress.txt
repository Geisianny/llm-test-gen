Feature: Manage banned addresses
Description: In order to manage banned addresses
  as a super admin
  I need to be able to delete them through the API.

Scenario 1: Remove banned address
  Tags: ['@createSchema']
  Given  I add Brand Authorization header
  When  I add "Content-Type" header equal to "application/json"
  And  I add "Accept" header equal to "application/json"
  And  I send a "DELETE" request to "/banned_addresses/3"
  Then  the response status code should be 405

Scenario 2: Cannot remove non antibruteforce banned address
  Given  I add Brand Authorization header
  When  I add "Content-Type" header equal to "application/json"
  And  I add "Accept" header equal to "application/json"
  And  I send a "DELETE" request to "/banned_addresses/antibruteforce/2"
  Then  the response status code should be 403

Scenario 3: Remove antibruteforce banned address
  Given  I add Brand Authorization header
  When  I add "Content-Type" header equal to "application/json"
  And  I add "Accept" header equal to "application/json"
  And  I send a "DELETE" request to "/banned_addresses/antibruteforce/3"
  Then  the response status code should be 204
