Feature: Manage transformation rules
Description: In order to manage transformation rules
  As a brand admin
  I need to be able to delete them through the API.

Scenario 1: Remove a transformation rule
  Tags: ['@createSchema']
  Given  I add Brand Authorization header
  When  I add "Content-Type" header equal to "application/json"
  And  I add "Accept" header equal to "application/json"
  And  I send a "DELETE" request to "/transformation_rules/4"
  Then  the response status code should be 204

Scenario 2: Cannot remove unmanaged transformation rule
  Tags: ['@createSchema']
  Given  I add Brand Authorization header
  When  I add "Content-Type" header equal to "application/json"
  And  I add "Accept" header equal to "application/json"
  And  I send a "DELETE" request to "/transformation_rules/5"
  Then  the response status code should be 404

Scenario 3: Cannot remove a generic transformation rule
  Given  I add Brand Authorization header
  When  I add "Content-Type" header equal to "application/json"
  And  I add "Accept" header equal to "application/json"
  And  I send a "DELETE" request to "/transformation_rules/9"
  Then  the response status code should be 403
