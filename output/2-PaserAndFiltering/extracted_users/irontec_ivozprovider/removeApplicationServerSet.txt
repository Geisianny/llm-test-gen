Feature: Manage application server set
Description: In order to manage application server set
  as a super admin
  I need to be able to delete them through the API.

Scenario 1: Remove a application server set
  Tags: ['@createSchema']
  Given  I add Authorization header
  When  I add "Content-Type" header equal to "application/json"
  And  I add "Accept" header equal to "application/json"
  And  I send a "DELETE" request to "/application_server_sets/2"
  Then  the response status code should be 204

Scenario 2: application server set with id zero is readonly
  Tags: ['@createSchema']
  Given  I add Authorization header
  When  I add "Content-Type" header equal to "application/json"
  And  I add "Accept" header equal to "application/json"
  And  I send a "DELETE" request to "/application_server_sets/0"
  Then  the response status code should be 403
