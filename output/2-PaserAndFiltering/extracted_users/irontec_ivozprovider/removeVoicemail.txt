Feature: Manage voicemails
Description: In order to manage voicemails
  As a client admin
  I need to be able to delete them through the API.

Scenario 1: Remove a voicemail
  Tags: ['@createSchema']
  Given  I add Company Authorization header
  When  I add "Content-Type" header equal to "application/json"
  And  I add "Accept" header equal to "application/json"
  And  I send a "DELETE" request to "/voicemails/3"
  Then  the response status code should be 204

Scenario 2: Remove a voicemail from a user
  Given  I add Company Authorization header
  When  I add "Content-Type" header equal to "application/json"
  And  I add "Accept" header equal to "application/json"
  And  I send a "DELETE" request to "/voicemails/1"
  Then  the response status code should be 403

Scenario 3: Remove a voicemail from a residential device
  Given  I add Residential Company Authorization header
  When  I add "Content-Type" header equal to "application/json"
  And  I add "Accept" header equal to "application/json"
  And  I send a "DELETE" request to "/voicemails/2"
  Then  the response status code should be 403

Scenario 4: Remove a voicemail from another company
  Given  I add Company Authorization header
  When  I add "Content-Type" header equal to "application/json"
  And  I add "Accept" header equal to "application/json"
  And  I send a "DELETE" request to "/voicemails/5"
  Then  the response status code should be 404
