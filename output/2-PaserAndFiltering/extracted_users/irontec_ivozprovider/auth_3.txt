Feature: Authorization checking
Description: In order to use the API
  As a client software developer
  I need to be authorized to access a given resource.

Scenario 1: An anonymous user retrieve a secured resource
  Tags: ['@createSchema']
  When  I add "Accept" header equal to "application/ld+json"
  And  I send a "GET" request to "users_cdrs"
  Then  the response status code should be 401

Scenario 2: An authenticated user retrieve a secured resource
  Given  I add User Authorization header
  And  I add "Accept" header equal to "application/ld+json"
  And  I send a "GET" request to "users_cdrs"
  Then  the response status code should be 200
  And  the response should be in JSON

Scenario 3: An authenticated user retrieve a secured resource
  Given  I add User Authorization header
  And  I add "Accept" header equal to "application/json"
  And  I send a "GET" request to "/my/profile"
  Then  the response status code should be 200
  And  the response should be in JSON

Scenario 4: Unauthenticated users cannot retrieve a secured resource
  And  I add "Accept" header equal to "application/json"
  And  I send a "GET" request to "/my/profile"
  Then  the response status code should be 401

Scenario 5: A higher order admin can exchange token
  When  I exchange User Authorization header
  And  I add "Accept" header equal to "application/ld+json"
  And  I send a "GET" request to "/my/profile"
  Then  the response status code should be 200
  And  the response should be in JSON
