Feature: Manage external call filter black lists
Description: In order to manage external call filter black lists
  As a client admin
  I need to be able to delete them through the API.

Scenario 1: Remove an external call filter black list
  Tags: ['@createSchema']
  Given  I add Company Authorization header
  When  I add "Content-Type" header equal to "application/json"
  And  I add "Accept" header equal to "application/json"
  And  I send a "DELETE" request to "/external_call_filter_black_lists/1"
  Then  the response status code should be 204
