Feature: Manage special numbers
Description: In order to manage special numbers
  as a brand admin
  I need to be able to delete them through the API.

Scenario 1: Remove a special numbers
  Tags: ['@createSchema']
  Given  I add Brand Authorization header
  When  I add "Content-Type" header equal to "application/json"
  And  I add "Accept" header equal to "application/json"
  And  I send a "DELETE" request to "/special_numbers/2"
  Then  the response status code should be 204

Scenario 2: Cannot remove a global special numbers
  Given  I add Brand Authorization header
  When  I add "Content-Type" header equal to "application/json"
  And  I add "Accept" header equal to "application/json"
  And  I send a "DELETE" request to "/special_numbers/1"
  Then  the response status code should be 403
