Feature: Audience > ActiveDocs preview page
Description: As a provider, I want a preview page to see what my ActiveDocs spec will look like and to manage
  it.
Tags: ['@javascript']

Background: 
  Given  a provider is logged in

Scenario Outline 1: Opening a product's spec will navigate to Product context - Example 1
  Given  the product has a Swagger 1.2 spec "Echo API"
  When  they go to the ActiveDocs page
  And  follow "Echo API"
  Then  the current page is the spec's preview page from Product context

  Examples:
    | swagger version |
    | Swagger 1.2 |
    | Swagger 2 |
    | OAS 3.0 |

Scenario Outline 2: Opening an unattached spec will navigate to Audience context - Example 1
  Given  the provider has a Swagger 1.2 spec "Unknown API Spec"
  When  they go to the ActiveDocs page
  And  follow "Unknown API Spec"
  Then  the current page is the spec's preview page from Audience context

  Examples:
    | swagger version |
    | Swagger 1.2 |
    | Swagger 2 |
    | OAS 3.0 |

Scenario Outline 3: Hide the spec - Example 1
  Given  the product has a Swagger 1.2 spec "Echo API"
  And  the spec is published
  When  they go to the spec's preview page from Audience context
  And  follow "Hide"
  Then  they should see a toast alert with text "Spec Echo API is now hidden"
  And  there should be a link to "Publish"

  Examples:
    | swagger version |
    | Swagger 1.2 |
    | Swagger 2 |
    | OAS 3.0 |
