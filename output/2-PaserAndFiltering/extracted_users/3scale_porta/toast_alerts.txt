Feature: Toast alert notifications
Description: As a user I want to see toast alert notifications that will automatically go away after 5 seconds.
Tags: ['@javascript']

Background: 
  Given  a provider is logged in
  And  they go to the provider dashboard

Scenario 1: Timeout
  When  a toast alert is displayed with text "Notice for you."
  But  after 8 seconds
  Then  they should not see any toast alerts

Scenario 2: Close alert manually
  Given  a toast alert is displayed with text "This is closeable"
  When  press "Close alert"
  Then  they should not see any toast alerts

Scenario Outline 3: Display toasts - Example 1
  When  a default toast alert is displayed with text "Hello Pepe!"
  Then  they should see a default toast alert with text "Hello Pepe!"

  Examples:
    | type | message |
    | default | Hello Pepe! |
    | info | Info for Pepe |
    | success | Pepe was a success |
    | warning | Watch out, Pepe! |
    | danger | Pepe alert! |
