Feature: Content Autosave

Scenario 1: Autosave item
  Tags: ['@auth']
  Given  empty "archive_autosave"
  Given  "archive"
  When  we post to "/archive_autosave"
  Then  we get existing resource
  When  we get "/archive_autosave/item-1"
  Then  we get existing resource

Scenario 2: Autosave does not accept invalid item
  Tags: ['@auth']
  Given  empty "archive"
  Given  empty "archive_autosave"
  When  we post to "/archive_autosave"
  Then  we get error 404

Scenario 3: Keep autosave on locked item
  Tags: ['@auth']
  Given  empty "archive_autosave"
  Given  "archive"
  When  we post to "/archive_autosave"
  Then  we get existing resource
  When  we post to "/archive/item-1/lock"
  Then  item "item-1" is locked
  When  we get "/archive_autosave/item-1"
  Then  we get existing resource

Scenario 4: Clean autosave on item save
  Tags: ['@auth']
  Given  empty "archive_autosave"
  Given  "archive"
  When  we post to "/archive_autosave"
  Then  we get existing resource
  When  we patch "/archive/item-1"
  Then  we get OK response
  When  we get "/archive_autosave/item-1"
  Then  we get error 404
