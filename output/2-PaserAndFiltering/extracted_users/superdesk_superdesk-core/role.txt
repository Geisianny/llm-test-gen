Feature: Role Resource

Scenario 1: List empty user roles
  Tags: ['@auth']
  Given  empty "roles"
  When  we get "/roles"
  Then  we get list with 0 items

Scenario 2: Set privileges to a given role
  Tags: ['@auth']
  Given  "roles"
  When  we patch given
  And  we get given
  Then  we get "privileges"

Scenario 3: Revoke privileges from a given role
  Tags: ['@auth', '@notification']
  Given  "roles"
  When  we patch given
  Then  we get updated response
  Then  we get notifications

Scenario 4: Check permissions on read with role
  Tags: ['@auth']
  Given  "roles"

  When  we get "/ingest"
  Then  we get response code 200
