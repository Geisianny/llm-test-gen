Feature: Contacts

Scenario 1: Create a contact
  Tags: ['@auth', '@notification']
  Given  empty "contacts"
  When  we post to "/contacts"
  Then  we get response code 201
  When  we get "/contacts"
  Then  we get existing resource
  Then  we get notifications

Scenario 2: Get contacts
  Tags: ['@auth']
  Given  "contacts"
  When  we get "contacts"
  Then  we get existing resource

Scenario 3: Get active contacts
  Tags: ['@auth']
  Given  "contacts"
  When  we get "/contacts"
  Then  We get list with 1 items

Scenario 4: Get all contacts
  Tags: ['@auth']
  Given  "contacts"
  When  we get "/contacts?all=1"
  Then  We get list with 2 items

Scenario 5: Get a contact
  Tags: ['@auth']
  Given  "contacts"
  When  we get "/contacts/4"
  Then  we get existing resource

Scenario 6: Search for a contact
  Tags: ['@auth']
  Given  "contacts"
  When  we get "/contacts?q=jane+d"
  Then  we get existing resource
  When  we get "/contacts?q=jane+d&contact_type=y"
  Then  we get list with 0 items
  When  we get "/contacts?q=jane+d&contact_type=x"
  Then  we get list with 1 items

Scenario 7: Delete a contact
  Tags: ['@auth', '@notification']
  Given  "contacts"
  When  we delete "/contacts/1"
  Then  we get response code 204
  When  we get "/contacts?all=1"
  Then  We get list with 0 items
  Then  we get notifications

Scenario 8: Update a contact
  Tags: ['@auth', '@notification']
  Given  "contacts"
  When  we patch "/contacts/1"
  When  we get "/contacts/1"
  Then  we get existing resource
  Then  we get notifications
  When  we patch "/contacts/1"
  Then  we get updated response
  When  we patch "/contacts/1"
  Then  we get updated response
  When  we patch "/contacts/1"
  Then  we get error 400

Scenario 9: Update a contact without permission
  Tags: ['@auth']
  Given  "contacts"
  When  we patch "/contacts/1"
  When  we switch user
  When  we patch "/users/#USERS_ID#"
  When  we patch "/contacts/1"
  Then  we get error 403

Scenario 10: Search for organisation
  Tags: ['@auth']
  Given  "contacts"
  When  we get "/contacts/organisations?q=foo so"
  Then  we get list with 1 items

Scenario 11: Search for organisation with no duplicates
  Tags: ['@auth']
  Given  "contacts"
  When  we get "/contacts/organisations?q=foo"
  Then  we get list with 2 items
