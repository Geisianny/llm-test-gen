  Given  we configure the languages
  Then  we cannot see the text "calendrier"

  Examples:
    | word | language |
    | calendrier | Français |
    | Kalender | Deutsch |
    | calendario | Español |

  Given  we add the calendar "event-with-html-markup"

  When  we look at 2024-04-14
  Then  we can see the text "MONTH"

  Examples:
    | word | language |
    | MONTH | en |
