Feature: Editing a customer group
Description: In order to change information about a customer group
    As an Administrator
    I want to be able to edit the customer group
Tags: ['@managing_customer_groups']

Background: 
  Given  the store has a customer group "Retail"
  And  I am logged in as an administrator

Scenario 1: Changing name of an existing customer group
  Tags: ['@ui', '@api']
  When  I want to edit this customer group
  And  I specify its name as "Wholesale"
  And  I save my changes
  Then  I should be notified that it has been successfully edited
  And  this customer group with name "Wholesale" should appear in the store

Scenario 2: Seeing disabled code field while editing customer group
  Tags: ['@ui', '@api']
  When  I want to edit this customer group
  Then  I should not be able to edit its code
