Feature: Shipping category validation
Description: In order to avoid making mistakes when managing a shipping category
    As an Administrator
    I want to be prevented from adding it without specifying required fields
Tags: ['@managing_shipping_categories']

Background: 
  Given  the store operates on a single channel in "United States"
  And  I am logged in as an administrator

Scenario 1: Trying to add a new shipping category without specifying its code
  Tags: ['@ui', '@api']
  When  I want to create a new shipping category
  And  I name it "Standard"
  But  I do not specify its code
  And  I try to add it
  Then  I should be notified that code is required
  And  shipping category with name "Standard" should not be added

Scenario 2: Trying to add a new shipping category without specifying its name
  Tags: ['@ui', '@api']
  When  I want to create a new shipping category
  And  I specify its code as "STANDARD"
  But  I do not specify its name
  And  I try to add it
  Then  I should be notified that name is required
  And  shipping category with name "Standard" should not be added
