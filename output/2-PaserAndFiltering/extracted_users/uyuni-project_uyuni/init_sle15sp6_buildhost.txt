Feature: Prepare buildhost and build OS image for SLES 15 SP6
Tags: ['@proxy', '@sle15sp6_buildhost']

Scenario 1: Log in as admin user
  Given  I am authorized for the "Admin" section

Scenario 2: Clean up sumaform leftovers on a SLES 15 SP6 build host
  When  I perform a full salt minion cleanup on "sle15sp6_buildhost"

Scenario 3: Prepare activation key for SLES 15 SP6 build host
  When  I create an activation key including custom channels for "sle15sp6_buildhost" via API

Scenario 4: Bootstrap the SLES 15 SP6 build host
  When  I follow the left menu "Systems > Bootstrapping"
  Then  I should see a "Bootstrap Minions" text
  When  I enter the hostname of "sle15sp6_buildhost" as "hostname"
  And  I enter "22" as "port"
  And  I enter "root" as "user"
  And  I enter "linux" as "password"
  And  I select "1-sle15sp6_buildhost_key" from "activationKeys"
  And  I select the hostname of "proxy" from "proxies" if present
  And  I click on "Bootstrap"
  And  I wait until I see "Bootstrap process initiated." text
  And  I wait until onboarding is completed for "sle15sp6_buildhost"

Scenario 5: Install kiwi10
  When  I install package "python11-kiwi" on this "sle15sp6_buildhost"

Scenario 6: Check the new bootstrapped SLES 15 SP6 build host in System Overview page
  When  I follow the left menu "Salt > Keys"
  Then  I should see a "accepted" text
  And  the Salt master can reach "sle15sp6_buildhost"

Scenario 7: Check connection from SLES 15 SP6 minion to proxy
  Tags: ['@proxy']
  Given  I am on the Systems overview page of this "sle15sp6_buildhost"
  When  I follow "Details" in the content area
  And  I follow "Connection" in the content area
  Then  I should see "proxy" short hostname

Scenario 8: Check registration on proxy of SLES 15 SP6 minion
  Tags: ['@proxy']
  Given  I am on the Systems overview page of this "proxy"
  When  I follow "Details" in the content area
  And  I follow "Proxy" in the content area
  Then  I should see "sle15sp6_buildhost" hostname
