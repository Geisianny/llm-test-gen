Scenario Outline 1: Navigation - Example 1
  Given  the product has a Swagger 1.2 spec "Echo API"
  When  they go to the product's ActiveDocs page
  And  follow "Echo API"
  Then  the current page is the spec's preview page from Product context

  Examples:
    | swagger version |
    | Swagger 1.2 |
    | Swagger 2 |
    | OAS 3.0 |
